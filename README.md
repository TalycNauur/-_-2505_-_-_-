# Суть программы

Программа читает письма из папки `inbox`, определяет категорию каждого письма,
перемещает файл в нужную папку внутри `sorted_mail` и сохраняет отчёты в `reports`.


# Что делает приложение

-читает письма `.txt` и письма без расширения;
-обрабатывает пустые, бинарные и неизвестные файлы;
-классифицирует письма по ключевым словам;
-перемещает письма по смысловым папкам;
-пишет лог обработки и итоговую статистику;
-поддерживает режим `--dry-run`, когда файлы не перемещаются.


# Категории

-`Критичные моменты` - срочные сбои, недоступные системы, ошибки 500, мониторинг;
-`Запросы` - запросы доступов, VPN, GitLab, Confluence, Active Directory;
-`Аппаратура` - принтеры, ноутбуки, гарнитуры, мыши, сканеры;
-`Поддержка ПО` - Chrome, Zoom, Excel, Adobe Reader, антивирус и обновления;
-`Документы` - договоры, счета, акты, документы;
-`Эйчар` - отпуск, больничный, график, оформление сотрудников;
-`Заявки клиентов` - обращения клиентов, партнёров, внешних пользователей;
-`Информация` - дайджесты, плановые отчёты, созвоны, приглашения;
-`Спам` - фишинг, подозрительные акции, просьбы сообщить логин и пароль;
-`Другое` - письмо прочитано, но не подошло ни под одно правило;
-`Ошибочные файлы` - файл нельзя прочитать или формат не поддерживается.

Такой подход устойчив к новым письмам: если письмо не совпало с правилами,
оно попадает в `Другое`, не ломает программу. Если файл повреждён или имеет
неподдерживаемый формат, он попадает в `Ошибочные файлы`, причина записывается в лог.

# Запуск

Обычный запуск:
```bash
bash run.sh
```
Этот способ выполняет реальную сортировку: письма будут перемещены из `inbox`
в папку `sorted_mail`.

Запуск напрямую через Python:
```bash
python3 main.py
```

Проверка без перемещения файлов:
```bash
python3 main.py --input inbox --output sorted_mail --reports reports --dry-run
```

После запуска:
-отсортированные письма лежат в `sorted_mail`;
-краткий отчёт лежит в `reports/summary.txt`;
-подробные действия лежат в `reports/actions.txt`;
-лог обработки лежит в `reports/processing.log`.

# Тесты

Тесты используют стандартный модуль `unittest`, поэтому отдельные зависимости не нужны.
```bash
python3 -m unittest discover -s tests
```

Тесты используют собственные временные файлы и не зависят от папки `inbox`.


# Архитектура

Пайплайн обработки: inbox -> MailReader -> MailClassifier -> MailProcessor -> sorted_mail + reports

-`MailReader` отвечает за чтение файлов.
-`MailClassifier` отвечает за выбор категории.
-`MailProcessor` объединяет чтение, классификацию, перемещение и отчёты.
